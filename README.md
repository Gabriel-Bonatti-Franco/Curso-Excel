1. ### Interface e navegação no Microsoft Excel
    Aprenda a conhecer o ambiente do Excel, incluindo a fita de opções, painéis, abas e atalhos de teclado essenciais para navegar eficientemente pela planilha.

2. ### Inserção e formatação de dados
    Descubra como inserir diferentes tipos de dados (texto, números, datas) e aplicar formatações visuais como fontes, cores, alinhamentos e estilos para melhorar a apresentação dos dados.

3. ### Fórmulas básicas (soma, média, etc.)
    Domine as operações matemáticas fundamentais do Excel, como soma, média, contagem e subtração, que formam a base para análises mais complexas.

4. ### Referências relativas e absolutas
    Entenda a diferença entre referências relativas (que se ajustam ao copiar) e absolutas (que permanecem fixas), essenciais para criar fórmulas reutilizáveis e precisas.

5. ### Funções essenciais (SE, PROCV, SOMASE, etc.)
    Explore funções poderosas como SE (condicional), PROCV (busca vertical), SOMASE (soma condicional) que automatizam decisões e buscas em grandes volumes de dados.

6. ### Formatação condicional
    Aplique regras visuais que mudam a aparência das células automaticamente com base em valores, destacando tendências e padrões importantes nos seus dados.

7. ### Tabelas e formatação de tabelas
    Converta dados em tabelas estruturadas do Excel para melhorar a organização, aplicar filtros automaticamente e facilitar a análise e gerenciamento de informações.

8. ### Classificação e filtros de dados
    Ordene e filtre seus dados de múltiplas formas para visualizar apenas as informações relevantes e organizar grandes conjuntos de dados de forma significativa.

9. ### Gráficos básicos e avançados
    Crie visualizações visuais como gráficos de barras, linhas e pizza (básicos) até gráficos mais sofisticados para comunicar insights e tendências de forma clara.

10. ### Validação de dados
     Implemente regras que controlam quais dados podem ser inseridos em células específicas, garantindo a qualidade e consistência das informações na planilha.

11. ### Funções de data e hora
     Trabalhe com funções especializadas para manipular, calcular e formatar datas e horas, útil para análises temporais e cálculos de prazos.

12. ### Funções de texto
     Domine funções para manipular texto, como concatenação, extração de caracteres, conversão de maiúsculas/minúsculas e limpeza de dados textuais.

13. ### Introdução a tabelas dinâmicas
     Aprenda a criar resumos automáticos de grandes volumes de dados através de tabelas dinâmicas, facilitando a análise exploratória e a geração de relatórios.

14. ### Tabelas dinâmicas avançadas
     Aprofunde seus conhecimentos em tabelas dinâmicas com técnicas avançadas, como múltiplos filtros, cálculos personalizados e atualização automática de dados.

15. ### Análise de dados (Atingir Meta, Solver, etc.)
     Utilize ferramentas de análise de cenários como Atingir Meta e Solver para resolver problemas complexos e encontrar valores ideais baseado em restrições específicas.

16. ### Proteção de planilhas e pastas de trabalho
     Implemente proteções com senhas para resguardar fórmulas, estruturas e dados sensíveis, controlando quem pode editar ou visualizar diferentes partes da planilha.

17. ### Automação com macros
     Crie macros para automatizar tarefas repetitivas no Excel, gravando sequências de ações que podem ser executadas com um clique para aumentar produtividade.

18. ### Introdução ao VBA (Visual Basic for Applications)
     Programem com VBA, a linguagem nativa do Excel, criando scripts customizados e funções personalizadas para resolver problemas específicos e avançados.

19. ### Power Query (importação e transformação de dados)
     Importe dados de múltiplas fontes e transforme-os usando Power Query, limpando, combinando e preparando informações para análise sem alterar os dados originais.

20. ### Power Pivot e modelagem de dados
     Crie modelos de dados relacionais sofisticados com Power Pivot, permitindo análises multidimensionais e relatórios poderosos em grandes volumes de dados.
